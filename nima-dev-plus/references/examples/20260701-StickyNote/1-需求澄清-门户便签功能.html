🐴 【需求澄清】门户便签功能

需求号：20260701 │ 作者：stone │ 2026-07-01 10:00

一、需求背景

茂松门户起始页已支持"常用工具"模块，当前有"发票打印"工具。用户希望在门户中快速记录临时信息（备忘、待办、灵感等），参考 Windows 便签（Sticky Notes）的轻量体验。便签工具需要支持用户快速创建、编辑内容并实时保存，数据持久化到后端数据库，确保多设备同步和长期保留。

二、业务目标
目标衡量标准
提供轻量便签能力用户可在起始页一键创建便签，无需跳转其他页面
实时保存编辑内容后自动保存，无需手动点击保存按钮
数据持久化便签内容存储于后端数据库，登录用户跨设备可访问
与现有工具体系一致入口、交互风格与"发票打印"工具保持一致
三、需求范围

包含

  • 起始页"常用工具"新增"便签"入口
  • 便签弹窗/面板：展示当前用户所有便签列表
  • 创建便签：点击新增按钮创建空白便签
  • 编辑便签内容：点击便签区域即可编辑，支持多行文本
  • 实时保存：编辑内容防抖后自动保存到后端
  • 删除便签：支持删除单条便签（二次确认）
  • 后端 CRUD 接口：创建、查询、更新、删除
  • 数据库表设计：便签表（用户隔离）

不包含（明确排除）

  • 便签拖拽移动 / 调整大小（本期不做）
  • 便签颜色标记 / 分类（本期不做）
  • 便签最小化 / 折叠（本期不做）
  • 便签分享 / 协作（本期不做）
  • 富文本编辑（仅纯文本）
  • 附件 / 图片上传
  • 便签搜索 / 筛选

五、技术约束
约束项要求
认证方式使用 Sa-Token 获取当前登录用户，便签数据按用户隔离
后端框架使用 continew-crud 的 CrudRequestMapping 快速生成 CRUD 接口
前端入口遵循现有 print-tool 模式：config 配置 + index.vue 分发 + tools/xxx-tool 组件
实时保存前端防抖（500ms）后调接口，避免频繁请求
接口规范遵循现有 /ms-boot 代理路径，API 前缀 /busi/stickyNote

八、前置条件
  • ms-iam 后端项目可正常编译运行
  • MySQL 数据库可连接
  • 开发者了解 continew-crud 的 CrudRequestMapping 使用方式
  • 前端 pnpm install 依赖已安装
九、验收标准
  1. 起始页"常用工具"区显示"便签"入口卡片，图标为 📝
  2. 点击"便签"打开便签管理弹窗，展示当前用户所有便签列表
  3. 点击"新建便签"按钮，创建一条空白便签，自动聚焦编辑
  4. 编辑便签内容后 500ms 内自动保存，页面不闪烁/不卡顿
  5. 刷新页面后便签内容正确从后端加载
  6. 删除便签时弹出二次确认，确认后便签从列表移除
  7. 不同用户的便签数据互相隔离（A 用户看不到 B 用户的便签）
  8. 后端接口遵循 RESTful 风格，支持 CRUD 操作
  9. 数据库表包含必要字段：id, user_id, content, create_time, update_time, deleted
